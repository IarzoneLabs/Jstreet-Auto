# Prompt Siap Pakai untuk Meminta Bantuan AI

Jika Anda memakai **Antigravity, Cursor, Claude Code, Codex, atau ChatGPT**, cukup buka folder project ini lalu salin & kirim salah satu prompt di bawah ini:

---

### 1. Untuk Setup dari Nol sampai Online (Paling Direkomendasikan)
> Tolong bantu saya setup project **JobStreet Auto-Matcher** di folder ini dari nol sampai online (100% gratis / Rp 0) berdasarkan `PANDUAN_SETUP_LENGKAP.md` dan `AGENTS.md`. Pandu saya **satu langkah per satu langkah**, mulai dari Supabase, Gemini API Key, GitHub, sampai Vercel, dan konfirmasi dulu sebelum lanjut ke langkah berikutnya.

### 2. Untuk Kustomisasi (Ubah Jam Otomasi / Tambah Skill / Ubah Bahasa)
> Tolong baca `AGENTS.md` dan `README.md` di folder ini. Saya ingin menyesuaikan project ini untuk bidang pekerjaan saya yaitu **[ISI BIDANG ANDA, misal: Digital Marketing / Software Engineer / Supply Chain]**. Tolong sesuaikan katalog skill di `worker/cv_parser.py` & `web/src/lib/cv-extract.ts` serta aturan rekomendasi keyword di `web/src/app/api/research/suggest/route.ts`.

### 3. Untuk Troubleshooting Error
> Saya mengalami kendala saat menjalankan JobStreet Auto-Matcher: **[TEMPEL PESAN ERROR / SCREENSHOT DI SINI]**. Tolong cek kode terkait berdasarkan `AGENTS.md` dan bantu perbaiki tanpa merusak fitur yang sudah berjalan.
